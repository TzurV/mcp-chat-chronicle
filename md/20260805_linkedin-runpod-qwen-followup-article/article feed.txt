Three things I learned about running small LLMs locally:

1. Faster hardware removes timeouts — but it cannot fix inputs that do not fit the context window.

2. A larger context window buys nothing if the machine cannot process it. On my laptop, moving from 8K to 16K recovered nothing; the failures merely changed from context errors to timeouts.

3. Context and compute have to grow together. Each alone left the context wall standing.

Using the same quantised 4B model, the same prompts and the same 120 real-work tasks:

Laptop, 8K context: 84/120 valid outputs
Stronger machine (rented GPU), 8K context: 89/120
Same machine, maximum context: 119/120
